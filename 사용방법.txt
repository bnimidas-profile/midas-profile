BNI 미다스 챕터 프로필 명함 보관함 - 관리자 버전

[포함된 멤버]
2026년 11월 25일 경청표 1쪽 정회원 31명, 가나다순.
번호 8 한기열 님은 경청표에서 ‘비지터’로 적혀 제외했습니다.
2쪽의 디렉터 이창무, 앰버서더 윤지윤 및 하단 비지터·참관인 5명은 제외했습니다.

[미리보기]
index.html을 열면 목록이 보입니다. 각 명함을 누르면 크게 볼 수 있고 다운로드할 수 있습니다.
아직 실제 명함 이미지는 등록되지 않았으며, 이름과 전문분야만 표시됩니다.

[관리]
admin.html 열기 → '사진 등록' → 사진 선택 → 저장
이름, 회사명, 전문분야도 수정하거나 멤버를 추가·삭제할 수 있습니다.
변경은 같은 브라우저의 임시 저장소에 보관됩니다. 이 기능은 공개 서버 데이터베이스가 아닙니다.

[변경을 전체 방문자에게 공개하는 방법]
admin.html → '게시용 파일 다운로드 (data.js)'
기존 사이트의 data.js 파일을 이 파일로 교체하고 GitHub Pages/Netlify 등으로 다시 배포합니다.
이때 방문자에게 새로운 명단/사진이 보입니다. 파일 크기가 커지면 GitHub에 업로드 제한이 생길 수 있습니다.

[중요]
이 버전에는 공개 사이트에서 보호되는 관리 로그인이나 클라우드 자동 게시가 없습니다.
안전하게 원격에서 편집하고 저장과 동시에 모두에게 반영하려면 별도 백엔드/인증 설정이 필요합니다.
명함 이미지에 개인정보가 포함되어 있다면 멤버의 공개 동의를 받으세요.

[구성 파일]
index.html: 공개 프로필 화면
admin.html: 관리자 입력 화면
style.css, app.js, admin.js: 화면 동작
data.js: 모든 멤버 정보 및 이미지 데이터
placeholder.svg: 명함 미등록 표시
